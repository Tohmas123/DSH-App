================================================================================
  DSH-App（DSH 启动器）—— 软件介绍
================================================================================

把 DeepSeek Harness 变成双击就能用的桌面程序。

版本 1.0.0        适用系统：Windows 10 / 11（64 位）


--------------------------------------------------------------------------------
  一、它解决什么问题
--------------------------------------------------------------------------------

DeepSeek Harness 是一个很强大的东西：它能读写文件、执行命令、连插件，把模型
变成一个真正能替你干活的助手。

但要把它跑起来，你需要先装 Node.js，然后在终端里敲命令、等它下载两百多兆的
运行文件、处理各种环境问题。这一步挡住了绝大多数人。

DSH-App 就是为这一步而生的：它把"装环境、起服务、连界面"这些事全部接过来，
用户只需要双击一个图标。

一句话概括：harness 是引擎，DSH-App 是把引擎接到轮子上的那套装置。


--------------------------------------------------------------------------------
  二、亮点
--------------------------------------------------------------------------------

【1】双击就用，不需要懂终端

    全程图形界面向导：自动检测环境 -> 需要什么就告诉你装什么 -> 点一下就开始。
    不需要打开过命令行。


【2】会自己发现并说清问题，而不是丢一个报错

    启动失败时它会分辨原因，用中文说明并给出可点的下一步：

      · 缺 Node.js
        显示图文安装引导，附官网链接
      · Node 版本过旧
        直接告诉你需要更新，并给出下载入口
      · 组件下载不完整（历史上真实出现过）
        提供「自动修复并重试」一键修复
      · 网络不通
        明确说是网络问题，让你「重试」而不是重装
      · 端口被占用
        告诉你是哪个程序占的，让你换个端口；
        如果占用者正是它自己上次留下的服务，还会提供一键结束
      · 端口被 Windows 保留
        明确告诉你没有任何程序占用它，只能换一个，不会误导你去找


【3】首次下载有真实进度，不是转圈

    第一次运行需要联网下载约 200 MB 的运行文件。DSH-App 会实时显示已经下载了
    多少个依赖包、多少体积、按当前速度还需多久——这些数字来自磁盘上真实的
    文件，不是估算出来的假进度条。

    示例：正在启动服务：已下载 42 个依赖包（约 40 MB），按当前速度大约还需 50 秒


【4】常驻控制面板：状态一眼可见

    程序不会一闪而过。它在任务栏右下角常驻，随时能看到：

      · 服务运行中：3099 端口　进程 1234   （当前状态与端口）
      · 一键打开界面（内置窗口或默认浏览器，两种视图互不影响）
      · 一键停止 / 重启服务，或修改服务端口
      · 一键打开工作目录 / 打开日志目录


【6】升级不会动你的数据

    程序文件、设置、对话、插件、工作区是分开存放的。升级只替换程序文件，
    对话、密钥、设置、插件一个都不会丢——这一点有自动化测试逐字节验证。


【7】干净、可审查、无后台小动作

      · 只用 Windows 自带的工具链构建：不需要 .NET SDK、不需要 NuGet、
        没有第三方运行时
      · 整个程序约 1 MB，分发包 512 KB
      · 不驻留后台服务、不做遥测、不上报任何数据——代码全部可读


【8】卸载干净，且由你决定删什么

    提供图形卸载程序，并注册进 Windows「应用和功能」。删除范围由你勾选：

      默认删除：
        · 程序文件
        · 桌面与开始菜单快捷方式
        · 注册表项

      默认保留（勾选后才删）：
        · 你的设置与密钥
        · 对话、附件、插件（~/.dsh）
        · 工作区目录

    并且明确告知：以上都不会删 harness 本体（npm 缓存里的运行文件）。

    它还只删自己装的那些文件：如果你把绿色版解压进了一个本来就有别的文件的
    文件夹，卸载时那些文件会原样保留、目录也不会被清空。勾选删除数据时，
    界面会先把将要删除的目录完整列出来（含 ~/.dsh 的真实路径），确认之后才动手。


--------------------------------------------------------------------------------
  三、和直接用 harness 相比
--------------------------------------------------------------------------------

    项目            直接用 harness              用 DSH-App
    -------------   -------------------------   ---------------------------
    安装            装 Node.js，敲命令           双击安装包
    首次运行        终端里等，不知道在干什么     图形向导 + 真实进度
    出问题          看报错自己排查               中文说明 + 一键修复
    日常使用        记命令、记端口               托盘点一下 / 开机常驻
    换端口          改配置或加参数               界面里改


--------------------------------------------------------------------------------
  四、适合谁
--------------------------------------------------------------------------------

  · 想用 harness，但不熟悉终端的人
    这是它存在的首要理由。

  · 已经在用终端跑 harness 的人
    它会变成一个常驻的状态面板和便捷入口；两者可以并存，
    端口冲突时它会明确告诉你占用者是谁。

  · 需要给非技术同事或家人装一份的人
    一个安装包，一路下一步。


--------------------------------------------------------------------------------
  五、技术一览
--------------------------------------------------------------------------------

    当前版本       1.0.0
    运行环境       Windows 10 / 11 + WebView2 运行时（通常已内置）
    构建方式       Windows 自带 csc.exe，无外部依赖
    程序体积       安装后约 961 KB（8 个文件）；分发包 512 KB
    界面           本地回环 HTTP 上运行的原生页面
                   （不使用 file://，因此没有跨域与 cookie 问题）

    数据位置：
      程序文件     %LOCALAPPDATA%\Programs\DSH-App
      设置与日志   %LOCALAPPDATA%\DSH-App
      对话与插件   ~/.dsh
      工作区       默认 Documents\DSH-App-Workspace


--------------------------------------------------------------------------------
  六、已知边界（如实说明）
--------------------------------------------------------------------------------

  · 首次运行需要联网下载约 200 MB，视网速可能要几分钟。
    程序会显示真实进度，但这一步无法跳过。

  · 不提供"检查新版本"功能。
    升级由发布者手动分发安装包，程序不会联网询问版本。

  · 不做无界面（headless）模式。
    本程序的存在理由是"让不会用终端的人也能用"，因此它始终提供图形界面。
    需要脚本化调用时，请直接使用 harness 自带的 dsh 命令。

  · 没有代码签名。
    Windows 可能显示「未知发布者」提示。这是发布者的选择，不影响程序行为。
    发布时会同时公布安装包的 SHA-256，用
        certutil -hashfile DSH-App-setup.exe SHA256
    即可核对，所以"文件有没有被换过"这件事仍然是可以自己验证的。
