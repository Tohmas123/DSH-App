## 安装

1. 拿到 **`DSH-App-setup.exe`**（约 512 KB，单文件）。
2. 双击运行。若 Windows 出现「未知发布者」提示，选择「更多信息 → 仍要运行」。
   > 本程序没有购买代码签名证书，这是已知情况，不影响功能。
3. 选择安装位置（默认 `%LOCALAPPDATA%\Programs\DSH-App`，**不需要管理员权限**）。
4. 一路「下一步」完成。桌面与开始菜单会出现快捷方式，并注册到「应用和功能」。

**想确认安装包没被改过**（可选）：发布时会同时公布 `DSH-App-setup.exe` 的 SHA-256。
在安装包所在文件夹打开命令行，运行：

```bat
certutil -hashfile DSH-App-setup.exe SHA256
```

把输出和公布的那串对比，**完全一致**就说明文件是完整的、就是发布出来的那一份。
不一致就不要运行它，重新下载。

**系统要求**

| 项 | 要求 |
|---|---|
| Windows | Windows 10 / 11（64 位） |
| 磁盘 | 程序约 1 MB；**首次运行另需约 360 MB**（运行文件 + 缓存） |
| 网络 | **首次运行必须联网**；之后日常使用不依赖网络 |
| WebView2 运行时 | Win10/11 通常已内置。若缺失，程序会明确提示并给出安装入口 |

## 第一次启动

双击图标后，程序会依次完成四件事。每一步都可以在界面上看到状态。

### 第 1 步：环境检测

程序检查四项，并把结果显示在同一个卡片上：

| 检查项 | 说明 |
|---|---|
| **Node.js 运行环境** | 没有就显示安装引导；版本过旧会直接说明需要更新 |
| **DeepSeek Harness** | 自动定位已下载的运行文件；找不到就会去下载 |
| **内置浏览器内核** | WebView2 是否可用 |
| **API 密钥** | 是否已有可用的密钥 |

- **缺 Node.js**：界面会展开图文引导，写明去 [nodejs.org](https://nodejs.org/) 下载 **LTS 版**、一路下一步、装完重开本程序。页面上有「**我装好了，重新检测**」按钮，不必重启程序。
- **Node 版本过旧**：同样有引导，点一下即可去更新。
- **其他问题**：见 [常见问题](#常见问题)。

### 第 2 步：填写 API 密钥（仅在需要时）

如果系统里还没有可用的密钥，会出现填写页面，粘贴后点「**保存并开始使用**」。

> 密钥只保存在本机（`%LOCALAPPDATA%\DSH-App\apikey.txt`），只交给 harness 使用，**不会上传到任何地方**。

### 第 3 步：首次下载运行文件

**这是最耗时的一步，也是最需要耐心的一步。**

- 需要联网下载约 **200 MB**（磁盘占用约 360 MB）
- 界面会显示**真实进度**，例如：
  `正在启动服务：已下载 42 个依赖包（约 40 MB），按当前速度大约还需 50 秒`
- 数字来自磁盘上真实的文件，会一直增长。**只要数字在涨，就说明一切正常。**

> 时长取决于网速：良好网络约 1–2 分钟；较慢或公司网络限制下可能更久。

### 第 4 步：控制面板

服务就绪后，你会看到控制面板。**到这一步，程序已经可以用了。**

## 日常使用：控制面板

控制面板是程序的主界面。它提供：

| 按钮 | 作用 |
|---|---|
| **在内置窗口中打开** | 在程序自己的窗口里打开聊天界面（推荐） |
| **在浏览器中打开** | 用你的默认浏览器打开。**两者可以同时使用**，互不影响，是同一个对话的两种视图 |

面板底部还会显示：

```
启动器 v1.0.0　·　harness v0.1.5-rc.2　·　想换端口？用托盘图标的「修改服务端口」
```

这行信息在排查问题时很有用——**它区分了「启动器」和「harness」两个版本**。

> 聊天回答里的链接会用**系统默认浏览器**打开，内置窗口始终留在对话界面。
> （这是刻意的：窗口要是被链接带走，你就得手动把它叫回来。）

> 关掉窗口时程序**不会退出**，而是缩到托盘继续在后台运行。这是刻意设计：关掉窗口不该中断助手的工作。

## 托盘菜单：全部功能

在任务栏右下角的托盘图标上**右键**，可以看到完整菜单：

| 菜单项 | 作用 |
|---|---|
| **显示窗口** | 把控制面板重新显示出来 |
| `服务运行中：3099 端口　进程 1234` | **只读状态行**：当前端口与正在服务的进程号。服务未运行时显示「服务未运行（已配置端口 3099）」 |
| **在浏览器中打开服务页面** | 用默认浏览器打开当前服务（需要时用） |
| **停止服务** | 停止 harness 服务（**不会**留下孤儿进程，比在任务管理器里强杀干净） |
| **重启服务** | 重启服务。**装了新插件后界面里看不到时，用这个** |
| **修改服务端口…** | 改端口，见下一节 |
| **打开工作目录** | 用资源管理器打开助手可以读写的文件夹 |
| **打开日志目录** | 用资源管理器打开日志文件夹（排查问题时需要） |
| **关于 DSH-App v1.0.0** | 显示启动器版本、**harness 版本**、程序目录、数据目录 |
| **退出** | 完全退出程序（同时停止服务） |

> 想彻底退出时请用菜单里的「**退出**」。直接关窗口只会最小化到托盘。

## 更换服务端口

**默认端口是 3099。** 以下情况需要改：

- 端口被别的程序占用（界面会告诉你是哪个进程号）
- 你想让 harness 和别的服务错开
- 该端口被 Windows 保留（界面会明确说明这种情况**没有程序占用**，只能换一个）

**操作方式（三种，任选）**

1. **托盘菜单 → 修改服务端口…**，输入新端口后确认，程序会问你是否立即重启服务
2. **控制面板上的「修改」**（在服务端口那一行），输入后点「保存」
3. **命令行**：`DSH-App.exe --port 3200`（见下节）

**端口范围**：1024–65535。

**输入被拒绝时会怎样**：界面**保留你输入的内容和输入框**，只在下面标红说明原因，改一下数字再点保存即可，不必重来。

## 升级

**升级只替换程序文件。你的对话、密钥、设置、插件、工作区都不会被改动**——这一点由自动化测试逐字节验证。

1. 拿到新的 `DSH-App-setup.exe`
2. 直接双击运行，**不必先手动退出旧版本**（安装程序会检测并处理正在运行的实例）
3. 安装程序会提示「升级 DSH-App」，并说明数据会被保留
4. 完成后打开程序即可

**如何确认升级成功**：托盘菜单 →「关于 DSH-App」，或在控制面板页脚看版本号。

> 本程序**不会自动检查更新**。请自行关注发布渠道获取新版安装包。

## 卸载

**方式一：Windows 设置**

「设置 → 应用 → 已安装的应用」→ 找到 **DSH-App** → 卸载。

**方式二：开始菜单**

开始菜单里找到 DSH-App 的卸载入口。

**方式三：程序目录**

直接运行安装目录里的 `Uninstaller.exe`。

**卸载界面会让你勾选删除范围**：

| 默认删除 | 默认保留（可勾选删除） |
|---|---|
| 程序文件、桌面与开始菜单快捷方式、注册表项 | `%LOCALAPPDATA%\DSH-App`（**密钥、设置、日志**） |
| | `~/.dsh`（**全部对话、附件、插件、凭据**） |
| | `Documents\DSH-App-Workspace`（**工作区文件**） |

> ⚠️ 勾选删除 `~/.dsh` 会**清空所有对话**，且**不可恢复**。界面会二次确认。
>
> 以上都不会删除 harness 本体（npm 缓存里的运行文件，约 214 MB）。若也要清掉，见 [常见问题](#常见问题)。

**两条关于"删得干净、但不多删"的说明**：

- 卸载程序**只删除它自己安装的那些文件**。如果你当初是把绿色版解压进了一个本来就有别的文件的
  文件夹，那些文件**会原样保留**，文件夹也不会被删掉（程序不会为了删自己而清空一个不属于它的目录）。
- 勾选删除数据后，界面会**把将要删除的目录完整列出来**（包括 `~/.dsh` 的真实路径——
  它可能被 `DSH_HOME` 环境变量指到别处），你确认之后才会开始删。

## 文件与数据位置

| 内容 | 位置 |
|---|---|
| 程序文件 | `%LOCALAPPDATA%\Programs\DSH-App` |
| 设置 | `%LOCALAPPDATA%\DSH-App\config.ini` |
| API 密钥 | `%LOCALAPPDATA%\DSH-App\apikey.txt` |
| 日志 | `%LOCALAPPDATA%\DSH-App\logs` |
| 对话 / 附件 / 插件 / 凭据 | `~/.dsh`（即 `C:\Users\<你>\.dsh`） |
| 工作区（助手可读写的文件夹） | 默认 `Documents\DSH-App-Workspace` |
| harness 运行文件 | `%LOCALAPPDATA%\npm-cache\_npx`（约 214 MB） |

**想改工作区**：直接编辑 `config.ini` 里的 `workspace=` 一行；也可以在托盘菜单用「打开工作目录」先看看现在指向哪。

设置文件长这样，**可以安全地手动编辑**：

```ini
# DSH-App settings. Safe to edit by hand.
# workspace = the folder the assistant may read and write
# zoom = interface scale, e.g. 1.15. Omit the line for 1.0 (Ctrl +/- still works)
port=3099
workspace=C:\Users\<你的用户名>\Documents\DSH-App-Workspace
setupDone=true
lastRunVersion=1.0.0
```

## 命令行参数（进阶）

普通用户**完全不需要**这些——不带参数双击就是正常用法。它们是为已经习惯命令行的人准备的。

```
DSH-App.exe [参数]

  --port <1024-65535>   设置服务端口，并写入设置文件
  --workspace <目录>    设置助手可读写的工作目录
  --reset-window        重置界面缩放（界面看起来不正常时用）
  --help                显示这段说明
```

示例：

```bat
:: 换到 3200 端口
DSH-App.exe --port 3200

:: 同时指定工作区
DSH-App.exe --port 3200 --workspace "D:\我的项目"
```

**设计约定**

- 参数**写进同一个 `config.ini`**，和界面里改端口是同一个地方——**不存在两套设置**
- **一个参数非法就整条拒绝**，不会"悄悄应用一半"，并在日志里记录原因
- `--help` 不需要窗口、不影响正在运行的程序

## 常见问题

### 启动失败：「缺少 sharp / 图片处理组件」

**原因**：上次下载不完整，少了平台二进制（历史上真实出现过）。
**处理**：点界面上的「**自动修复并重试**」，程序会自己补装。需要联网。

### 启动失败：提示网络问题

**原因**：下载运行文件时网络中断，或被公司网络/安全软件拦截。
**处理**：确认能访问 `registry.npmjs.org` 后，点「**重试**」。**不需要重装。**

### 卡在「首次下载」很久

**先看数字有没有在涨。**

- **数字在涨** → 正常，只是网速慢。等到完成即可。
- **数字长时间不动** → 网络可能被拦截。检查代理/防火墙是否允许 npm，然后重试。

### 提示端口被占用

界面会告诉你**占用者的进程号**：

- **如果那是你自己从终端启动的 harness** → 直接用它就行，或者换一个端口
- **如果是本程序上次遗留的服务** → 会出现「**结束那个进程并重新启动**」按钮，点它即可
- **如果是别的程序** → 程序**不会**去动它（这是刻意的设计），请换端口
- **如果提示是 Windows 保留的端口** → 没有任何程序占用它，关掉谁也腾不出来，只能换一个数字

### 界面显示"认证失败"或空白

**处理**：托盘菜单 → **重启服务**。多数情况下就能恢复。

### 装了插件但在界面里看不到

**处理**：托盘菜单 → **重启服务**。插件需要重新加载才会出现在界面上。

### 界面看起来过大/过小/错乱

**处理**：用 `--reset-window` 启动一次（见 [命令行参数](#命令行参数进阶)）。也可以在界面里按 `Ctrl` + `+` / `Ctrl` + `-` 或 `Ctrl` + 滚轮调整缩放。

### 想把 harness 运行文件也清掉（释放 214 MB）

程序**不会**自动删除它（因为别的工具可能也在用）。确认不再需要后，手动删除：

```
%LOCALAPPDATA%\npm-cache\_npx
```

下次启动时程序会重新下载（约 1–2 分钟）。

### 想反馈问题、需要提供什么

托盘菜单 → **打开日志目录**，把 `logs` 文件夹里的内容发给懂技术的人即可。
日志里包含版本号、harness 版本、每一步的时间与失败原因——**不包含你的对话内容，也不包含 API 密钥**。

> ⚠️ 但日志里**有本机服务的访问地址**，形如 `http://127.0.0.1:3080/?token=…`。
> 那串 token 相当于本机服务的钥匙，不过它**只在这台电脑上有效**，别人拿到也用不了。
> 如果你要把日志发到群里或论坛，稳妥起见先把 `app.log` 和 `server-*.out.log` 里
> `token=` 后面那一串删掉。

### 双击没反应 / 提示"已经在运行"

程序是**单实例**的：已经在运行时，第二次双击会提示并退出。
处理：看任务栏右下角托盘的图标，**双击它**即可把窗口叫回来。

## 附录：环境变量

这些是**开发/排障用**的开关，普通使用不需要设置。

| 变量 | 作用 |
|---|---|
| `DSH_APP_DEBUG_PORT=<端口>` | 开启 Chromium DevTools 端口，供自动化测试驱动界面。**用完请立刻删掉**：开着的时候，本机上的任何网页都能连上这个调试端口读到界面内容（文档里不推荐日常使用） |
| `DSH_APP_FORCE_WIZARD=1` | 强制显示填写密钥的步骤（本机已有密钥时默认会跳过） |

**自动化测试相关**（仅开发者）：

```
powershell -NoProfile -ExecutionPolicy Bypass -File test\run-all.ps1
```
